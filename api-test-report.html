需要修复的接口（5 个）

共性问题：缺少 CORS 响应头 + OPTIONS 预检处理。前端跨域 POST/DELETE 请求会被浏览器拦截。

  1. /api/auth — 口令验证/修改，前端修改密码的 POST 会被拦截
  2. /api/proxy — RSS 代理抓取，前端调用的 POST 会被拦截
  3. /api/wechat-material — 微信同步，前端 POST 同步文章会被拦截
  4. /api/random-image — 随机图片，前端 POST 上传图片会被拦截
  5. /api/ai/greeting — 问候语管理，前端 POST 管理词库会被拦截

修复方案

每个文件加两处改动（以 auth.js 为例）：

  1. 在 respond() 函数的 headers 里加 'Access-Control-Allow-Origin': '*'
  2. 在 onRequest 入口加 if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: CORS })
