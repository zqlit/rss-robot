博客 RSS 订阅聚合 · 数据由 GitHub Action 定时抓取

最新文章

GET /api/results

获取所有博客最新文章，支持按博客筛选和限制文章数。

# 获取全部 curl https://rssapi.usj.cc/api/results # 筛选特定博客 curl https://rssapi.usj.cc/api/results?feed=刘郎阁 # 每博客只取最新 3 篇 curl https://rssapi.usj.cc/api/results?limit=3

POST /api/proxy

RSS 抓取代理。通过国内节点抓取被境外封锁的博客。

# 代理抓取目标 URL curl -X POST https://rssapi.usj.cc/api/proxy \ -H "Content-Type: application/json" \ -d '{"url": "https://example.com/feed", "timeout": 15000}'

POST /api/update

接收抓取结果并存入 KV（由 GitHub Action 自动调用，无需手动触发）。

数据来源：RSS Robot · 代理服务：SCF 国内节点
